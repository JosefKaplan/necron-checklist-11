# Necron Turn Checklist

Turn checklist for Necrons in Warhammer 40,000 11th edition. Shows what you can do in each phase, tracks CP, detachments and stratagems. Built for phones. One file, no build.

**Live:** https://josefkaplan.github.io/necron-checklist-11/

## Deploy to GitHub Pages

1. On GitHub, create an empty **public** repository (no README), for example `necron-checklist-11`. A free account can only publish Pages from a public repository.
2. In this folder, run:

   ```bash
   git init
   git add .
   git commit -m "Necron Turn Checklist"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/necron-checklist-11.git
   git push -u origin main
   ```

3. In the repository, go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick **main** and **/ (root)**, then click **Save**.
4. Wait a minute or two, then open `https://YOUR-USERNAME.github.io/necron-checklist-11/`.

**To update:** commit and push. The site redeploys by itself.

## Good to know

- Anyone with the link can open the site. Search engines are asked not to list it.
- Your game is saved in your browser. Each device keeps its own.
- On your phone, use **Add to Home Screen** to open it like an app.
- To run it locally, just open `index.html`. Tests and notes for changes are in `CLAUDE.md`.
